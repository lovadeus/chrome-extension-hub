# Chrome Extension Hub

Crie uma plataforma SaaS profissional, moderna e responsiva para vender e gerenciar uma extensão do Google Chrome, conforme a especificação detalhada do usuário. Habilite Lovable Cloud primeiro para banco de dados, autenticação, APIs seguras, permissões ADMIN/CLIENTE e armazenamento/configurações. Implemente uma landing page completa, planos Diário/Mensal/Anual configuráveis, cadastro/login/recuperação de senha, checkout preparado para PIX e cartão com confirmação exclusivamente por webhook backend, geração e controle de licenças, dashboard do cliente, download configurável da extensão, tutorial administrável, painel administrativo completo (clientes, licenças, planos, pedidos/pagamentos, extensão, tutoriais, cupons, configurações, logs e suporte), modo claro/escuro e responsividade. Estruture as tabelas e relações descritas, políticas de acesso e API backend para ativar/validar/desativar/status de licença com proteção adequada. Não exponha segredos no frontend. Onde forem necessárias credenciais externas de gateway/email, deixe a integração segura preparada por variáveis de ambiente e documente as configurações pendentes. Use conteúdo de demonstração claramente identificável e uma identidade visual SaaS tecnológica de alto nível.
